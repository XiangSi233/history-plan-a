# 第15课 中国工农红军长征与遵义会议 · 剧情闯关版

把统编版八年级上册第 15 课的课件，做成了一部**可以玩的 galgame 式互动课件**：

**看剧情 → 进三维现场旁听会议 → 答对问题 → 推进下一章**

- **剧情模式**：立绘 + 背景 + 对话框，像视觉小说一样一屏屏推进；人物立绘会随发言高亮
- **跨学科知识卡**：剧情推进中会自动弹出「地理」「语文」知识卡（带示意图），把史实和学科知识接上
- **三维现场**：剧情走到"通道会议""遵义会议"时，可以进入真正的三维会场，拖动视角、点人物听他发言
- **答题闯关**：每章结束出题（多数取自本课"课堂练习"，重点章节还加了跨学科题），**答对才解锁下一章**，答错给提示可以重来
- **自由探索**：路线图模式仍然保留，老师上课可以随时跳出去自由讲

`hudong/` 是纯自由探索版，`hudong1/`（本目录）是剧情闯关版，两者互不影响。

## 一、怎么跑起来

因为用了 ES Module 和 `fetch`，**不能用 `file://` 双击打开**，需要一个静态服务器。

### 本地预览（最快）

```bash
cd hudong
python3 -m http.server 8123
# 浏览器打开 http://127.0.0.1:8123/
```

或者用 Node：

```bash
npx serve -l 8123 .
```

### 部署到服务器

整个 `hudong/` 目录就是**纯静态文件**，没有任何后端依赖，直接拷贝到网站根目录即可。**three.js 已经放在 `vendor/` 里，不需要联网、不依赖 CDN。**

nginx 示例：

```nginx
server {
    listen 80;
    server_name your.domain;
    root /var/www/hudong;
    index index.html;

    # 建议开启 gzip / brotli，assets 里是 webp，压缩收益有限但 html/css/js 明显
    gzip on;
    gzip_types text/css application/javascript application/json image/svg+xml;

    # 视频与图片加长缓存
    location ~* \.(webp|mp4|woff2?)$ {
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
    location = /index.html { add_header Cache-Control "no-cache"; }
}
```

放到校园网服务器 / 希沃白板 / 一体机本地也可以：把目录拷到机器上，用任意静态服务起一下（或者让学校网管配一个虚拟目录）。

> **离线演示**：教室断网也能用——所有素材、three.js 全在本地。

## 五、三维现场的人物（默认几何头部）

三维现场**默认是原版的几何头部**：低多边形人形 + 球体头部 + 红军八角帽 + 眼镜，
风格统一、干净，和程序化的房间/家具是一套语言。

**代码里保留了"真人照片贴到 3D 头部"的完整实现，默认不启用。** 想开的话，在
`js/data/scenes.js` 给对应人物加一行 `face:` 即可，例如：

```js
{ id: 'mao', name: '毛泽东', seat: [0.32, -0.98, 0],
  face: 'assets/face/mao.webp',      // ← 加这一行就启用真人脸；删掉就退回几何头部
  uniform: '#767b80', cap: false },
```

六张头像（`assets/face/*.webp`）已经做好放在项目里，共 96KB。

### 这个功能是怎么实现的

- **头部**是程序化生成的头形网格（球体经"收下颌、收额头、压后脑"变形），不是正球
- **脸**是把照片按**柱面（角度）包裹**贴上去：横向覆盖头部正面约 ±49°，纵向铺满头高
- **后脑**单独用深色头发半球，避免球体背面把正脸再映一遍
- 贴图边缘做了**径向渐隐到黑**，不会露出"方照片"的硬边
- 发言时该人物面部的自发光会提亮

### 什么时候值得开

现有头像是课件里的历史照片，**分辨率低、多为侧 3/4 视角**（周恩来那张还是从合影里裁的，
脸只有 90 像素），贴到 3D 头上近看会有"照片糊在球上"的感觉，所以默认关闭。

如果你能拿到**正面、高清、纯色背景**的肖像（AI 生成或高清史料），换上后效果会明显好于历史照片：

1. 图片**正方形、脸部居中、头顶到下巴约占画面高度 75%**
2. 存成 `assets/face/人名.webp`，在 `scenes.js` 里加上 `face:` 那一行
3. 想调效果改 `js/scene/room.js` 里这几项：

```js
const THMAX = .86;                  // 照片横向覆盖多少弧度（越大脸越宽）
const U_SPAN = .76, V_SPAN = .88;   // 用照片中间多少比例（越小脸越大）
headGrp.scale.set(.116*.96, .116*1.14, .116*1.0);   // 头的宽/高/厚
emissiveIntensity: .85              // 自发光，暗场景里保证看得清脸
```

## 六、改剧情 / 加题目 / 加知识卡

全部内容都在 **`js/data/story.js`**，一个章节一个对象：

```js
{
  id: 'ch2', no: '第二章', title: '通道转兵',
  place: '湖南 · 通道 · 1934年12月',
  bg: 'assets/map/route-simple.webp',        // 背景图
  cast: ['bogu','lide','zhou','mao','luofu'],// 本章出场人物（对应 assets/chara/*.webp）
  script: [
    { narr: true, text: '旁白……' },
    { who: 'mao', pos: 'right', text: '人物台词……' },   // pos: left / center / right
    { choices: [ { text:'选项', tone:'historic', reply:[{who:'zhou',text:'…'}] } ] },  // 分支
    { enterScene: 'tongdao', text: '进入三维现场' },      // 插一段 3D 现场
    { bg: 'assets/event/xxx.webp' },                     // 从这一行起换背景（淡入淡出）
    { geo: {                                             // 弹一张跨学科知识卡
        subject: '地理',                                  // 学科标签：地理 / 语文 / …
        title: '大渡河为什么被称为“天险”？',
        img: 'assets/geo/valley.webp',                    // 可选示意图
        quote: '诗句……',                                  // 可选引文（语文卡用）
        points: ['要点一', '要点二 <b>加粗</b>']
      } }
  ],
  quiz: {
    q: '题干……',
    options: ['A…','B…','C…','D…'],
    answer: 1,                                // 正确项下标（从 0 开始）
    tip: '答对后显示的解析',
    hint: '答错后显示的提示'                   // 可选，不写用默认提示
  }
}
```

- **加一章**：往 `CHAPTERS` 数组里加一个对象即可，进度条和章节圆点会自动变
- **加一题**：`quiz` 写成对象是单题，写成**数组就是多题连出**（第五章就是地理 + 语文两题）
- **加知识卡**：在 `script` 里插 `{ geo: {...} }`，按空格或点按钮收起
- **换背景**：插 `{ bg: '图片路径' }`，背景会淡出淡入地换掉
- **人物立绘**：`assets/chara/{id}.webp`，id 就是 `cast` 里写的名字；
  换图直接把同名文件覆盖即可（建议竖版、半身、正面）
- **出场人物表**：`CAST_INFO` 里改名字和身份，对话框的名牌和身份会跟着变

答题的判定、错题锁定、通关解锁在 `js/ui/quiz.js`，全局答题计数也在那里。

## 九、技术与兼容

- **无构建、无依赖、无后端**：原生 ES Module + 一个 import map 指向 `vendor/three.module.js`。
- **three.js r169**（本地），`WebGL` + `ACESFilmic` 色调映射。
- 房间贴图、木纹、砖墙、夜空、光晕**全部由 canvas 程序化生成**，不占素材体积。
- 人物用低多边形几何体拼装，含呼吸/点头动画与说话人高亮；`shadowMap` 仅油灯一盏，1024 阴影贴图，教室一体机也能流畅跑。
- 建议 Chrome / Edge 90+、Firefox 90+、Safari 15+（需要 WebGL2 与 WebP）。
- 若浏览器不支持 WebGL，进入现场时会给出提示，其余功能不受影响。
- 大屏建议 1920×1080 及以上、浏览器按 <kbd>F11</kbd> 全屏；页面按 16:9 自适应。

**想瘦身**：`assets/video/zunyi-clip.mp4` 占 14MB（总 18MB），不需要纪录片片段的话删掉它，并移除 `js/data/scenes.js` 里 zunyi 场景 `archive` 中的那一条即可，项目立刻降到约 4MB。

## 十、调试小技巧

页面暴露了两个全局对象，按 <kbd>F12</kbd> 在控制台可以直接用：

```js
__APP__.story.start(2)              // 直接跳到第 3 章（下标从 0 开始）
__APP__.quiz.totalRight             // 当前答对题数
__APP__.map.select('zunyi', true)   // 直接打开某个地点的事件卡
__SESSION__.speak('mao')            // 直接让毛泽东发言
```
